# User Management System

This project is a full-stack User Management System built as part of my IS218 coursework at NJIT. It demonstrates real-world software development practices including authentication, role-based access control, testing, and Docker-based deployment.

The goal of this project is to simulate a production-style environment where students contribute to an existing codebase by identifying bugs, improving test coverage, and implementing new features while maintaining a stable main branch.

## Key Objectives
- Perform quality assurance by identifying and documenting bugs
- Improve automated test coverage using Pytest
- Implement a new feature following existing architecture and best practices
- Maintain a working Docker deployment throughout development

## Tech Stack
- FastAPI
- SQLAlchemy & Alembic
- OAuth2 Authentication
- Pytest
- Docker & GitHub Actions

## Project Context
This repository was forked from the course base project and extended with my own QA issues, additional tests, and feature implementation as required for the final assignment.
